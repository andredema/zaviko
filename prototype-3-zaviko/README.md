# Zaviko · prototype cliquable

Prototype de la plateforme **Zaviko** (« Trouve qui sait faire. »), qui met en relation les habitants d'Ottawa–Gatineau avec des prestataires vérifiés.

> Toutes les données sont **fictives** : personnes, numéros de téléphone (555), avis et prix. Rien n'est enregistré, et les appels, textos et WhatsApp sont simulés.

## Ouvrir le prototype

Double-clique sur `index.html`. Il s'ouvre dans ton navigateur, sans installation ni serveur.
`guide.html` liste toutes les pages et des parcours à tester.

## Contenu

| Fichier | Rôle |
|---|---|
| `index.html` | Accueil : recherche, urgence, catégories |
| `recherche.html` | Résultats avec filtres et tri |
| `pro.html?id=…` | Profil public d'un prestataire |
| `contact.html?id=…` | Appeler, écrire, se faire rappeler (sans compte) |
| `devis.html` | Demande de devis express |
| `suivi.html` | Suivi d'une demande par code (démo : `ZK-4821`) |
| `urgence.html` | Premier pro disponible |
| `pro/inscription.html` | Inscription prestataire en 3 étapes |
| `pro/envoye.html` | Confirmation et étapes de validation |
| `pro/espace.html` | Espace pro : disponibilité, demandes, devis |
| `pro/modifier.html` | Édition de la page publique avec aperçu |
| `guide.html` | Plan du prototype |
| `assets/data.js` | Données fictives (pros, demandes) |
| `assets/app.js` | Fonctions communes (en-tête, cartes, icônes) |
| `assets/styles.css` | Styles et palette Zaviko |
| `assets/logo/` | Fichiers du logo (SVG) |

## Identité

- Couleurs : Encre `#0F2A3D`, Sarcelle `#0E9F8E`, Ambre `#F2A541`, Brume `#F6F8F7`, Ardoise `#5B6770`
- Typographies : Outfit (titres), Inter (texte), via Google Fonts
